# 隐私与水印路由

## 源图只读

- 不覆盖、不重命名、不移动源图。
- 开始处理前，把源图复制到当前任务的新版本目录。
- 标注、遮盖、裁切、拼板和水印处理都只作用于副本。
- 在 `resolved-plan.json` 中记录源图标识、副本标识和变换，不写入账号、个人信息或完整敏感内容。

源图路径若指向用户正在使用的目录，仍只读取；不得把 QA 文件写回源图目录。

## 敏感信息继承

衍生图、裁切图、总览、接触表和复核文件继承源图的最高敏感级别与传播限制。缩小、裁切或加框不会自动降低敏感级别。

如果源图的敏感级别未知：

1. 标记为待确认。
2. 限制在任务版本目录。
3. 不对外发布或上传。
4. 进入人工视觉门禁。

需要脱敏时，只在副本上执行明确的遮盖计划，并检查标注框、标签、裁切图和总览是否重新暴露信息。不得把未知值写成无敏感信息。

## 任务级最小化候选

并非只有直接个人信息才需要检查。以下内容若与教程目标无关，并且可能造成误解或暴露历史，也应列入当前任务的最小化候选：

- 失败记录。
- 退件或驳回状态。
- 办件编号、业务流水号或类似追踪值。
- 区县、街道等过细地域。
- 与当前教学步骤无关的历史列表项、状态或结果。

列为候选不表示自动判定为高风险，也不表示必须遮盖。先按相关性、敏感级别、误解风险和教学必要性分类，再决定保留、裁切、遮盖、替换为合成数据或更换截图。分类结果和处理理由必须进入任务审计。

不要把“与教程无关”直接等同为“高风险脱敏”，也不要因为它不是直接个人信息就跳过审计。

## 已过期一次性解压密码的任务级例外

默认仍把密码、验证码、令牌和凭证视为敏感信息。只有用户明确说明某个归档文件的解压密码是一次性的、已经过期，并明确要求为教程理解而展示时，才可以在新的工作副本中保留或恢复该字段，同时在审计中记录授权范围和理由。

该例外只适用于已确认过期的一次性归档解压密码，不得扩展到支付密码、登录密码、短信验证码、银行卡信息、API key、token、仍有效下载口令或其他凭证。无法确认字段类型、有效期或授权时继续脱敏并进入阻断。

## 上游审计绑定

当 `privacy.required` 为 `true` 时：

- `privacy.upstream_audit` 或逐素材 `privacy.upstream_audits` 必须指向可读取的上游审计 JSON/object。
- 每个 asset ID 必须有且只有一份可确定绑定的审计证据。
- 审计 JSON 中的 `output_sha256` 必须等于当前待标注脱敏副本的实际 SHA-256。
- 审计中的 `source_sha256` 只作为脱敏前原图的来源链保存，不能替代 `output_sha256`。
- 只有审计状态和哈希绑定都通过，`privacy.status` 才能写为 `passed`。

缺少审计、哈希不一致、审计绑定到其他源图或状态未知时进入阻断。不得因为文件名相同、画面相似或路径相近就假定审计仍然有效。

合成且明确不含敏感内容的示例素材可以使用 `required: false` 和 `status: not_required`；未知值保持 `null`，不得填写虚构哈希。

## 水印判断

先判断水印归属和授权：

- 未知版权水印：保留，不自动去除。
- 明确属于第三方且无授权：保留，并在对外交付前人工确认使用范围。
- 自有水印：可以进入确定性处理评估。
- 有明确授权的水印：可以进入确定性处理评估，并保留授权记录。

归属或授权任一项不清楚时，按未知版权水印处理。

## 确定性冲底

只有同时满足以下条件，才允许在副本上处理水印：

1. 水印属于自有内容，或已有明确授权。
2. 背景可以通过裁切、已知纯色填充或可重复的确定性背景延展完成冲底。
3. 不需要生成式猜测被遮挡的文字、图标、人物或界面内容。
4. 处理结果能够通过前后差异和人工复核确认。
5. 水印审计明确记录 `passed`、`authorized`、`deterministic`、`outside_changed_pixels: 0`，并用 `output_sha256` 绑定当前副本。

无法确定性冲底时保留水印。不得自动调用生成式擦除，也不得用模糊、涂抹或遮挡伪装成已恢复原内容。

## 路由表

| 情况 | 自动动作 | 人工门禁 |
| --- | --- | --- |
| 无水印，敏感级别明确 | 复制后按计划处理 | 检查衍生产物是否继承限制 |
| 未知版权水印 | 原样保留 | 确认版权与交付范围 |
| 第三方水印且无授权 | 原样保留 | 不得签核去除 |
| 自有或明确授权，能确定性冲底 | 仅在副本处理并记录变换 | 检查背景和内容未被猜测 |
| 自有或明确授权，不能确定性冲底 | 原样保留 | 决定是否更换素材 |
| 敏感级别未知 | 限制在任务目录 | 确认级别后再交付 |

## QA 要求

- 源图未发生写入。
- 所有衍生产物继承敏感限制。
- 与教程无关的失败记录、退件状态、办件编号和过细地域已经完成任务级分类与必要性审计。
- 必需的上游审计逐素材存在，审计的输出 SHA-256 与当前待标注脱敏副本一致。
- 未知水印没有被自动去除。
- 已处理水印具备自有或授权依据。
- 冲底方法可重复、可解释，没有生成式猜测。
- 裁切图和总览没有绕过遮盖重新暴露敏感信息。
- 已展示的过期一次性解压密码具备用户明确授权与任务级审计，且没有误放开其他密码、验证码或凭证。

任一项无法确认时加入 `blockers`，不得把自动 QA 写成已通过。
